# ALT-AIIDE website

ALT-AIIDE is a (satirical) version of the AAAI conference on AI and Interactive Digital Entertainment (AIIDE), where all papers are AI-generated. The website should contain a list of "accepted" papers (the ones in the papers/ directory), with their titles, authors and abstracts. It should also hype the innovation and scientific novelty contained within the papers in an over-the-top manner. AI generated images, graphics, or other visual elements are encouraged to give the page a tech-y and game-y feel. (AIIDE is about game AI, fundamentally). Graphics can take inspiration from the papers currently present in the papers/ directory (even if those might change in the future, things like Battleships or Backgammon are always appropriate to include somewhere on the page; just not for a specific paper).

## Tech Stack

The website will be hosted on github pages, and thus should use Jekyll. The list of papers is preliminary, though, so there should be a python script that takes all papers in the "papers" directory, and extracts title, author name, and the abstract to include on the page.
